# Administrador de activación de Windows

Herramienta en BAT para consultar y administrar la activación de Windows mediante herramientas integradas del sistema.

Desarrollada por Franluis Maldonado con asistencia de Codex.

## Funciones

- Consultar detalles y vencimiento de la activación.
- Instalar una clave de producto.
- Configurar un servidor KMS autorizado.
- Intentar activar Windows.
- Quitar el servidor KMS manual y restaurar la detección automática.

## Descarga y uso

1. Descarga Activacion-Windows.zip desde este repositorio.
2. Extrae los archivos.
3. Abre Activacion-Windows.bat.
4. Para modificar la configuración, haz clic derecho y selecciona «Ejecutar como administrador».
5. Elige una opción y sigue las instrucciones.

Cada cambio solicita confirmación. Consulta LEEME.txt para más detalles.

## Requisitos y limitaciones

- Requiere una licencia válida o acceso autorizado al KMS de tu organización.
- No incluye claves de producto ni servidores públicos.
- La clave debe corresponder a la edición de Windows instalada.
- Instalar una clave reemplaza la anterior.
- Quitar el servidor KMS manual no recupera la clave anterior.
- No desactiva Defender, firewall ni SmartScreen.
